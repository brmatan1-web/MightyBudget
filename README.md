## MightyBudget 2.0

### קבצים
- Code.gs: הקוד של הגיליון בגוגל. לא מעלים לגיטהאב.
- כל השאר: האפליקציה. מעלים למאגר MightyBudget.
- scrape.yml: קובץ הסנכרון. לא השתנה, אין צורך להחליף אותו במאגר הסנכרון.

### עדכון
1. בגוגל: מחליפים את כל הקוד ב־Code.gs, ושומרים. אם בעורך יש קבצי קוד נוספים ברשימה, מוחקים אותם.
2. מריצים פעם אחת את הפונקציה install ומאשרים הרשאות.
3. מפרסמים גרסה חדשה: Deploy, Manage deployments, New version.
4. מעלים את קבצי האפליקציה למאגר MightyBudget.
5. בכל טלפון פותחים את האפליקציה ובוחרים מי אתם.
