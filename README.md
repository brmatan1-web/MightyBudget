# MightyBudget – אבטיפוס מסכי אפליקציה

אפליקציית PWA בעברית, מותאמת לאייפון, לשני משתמשים.

## מה עובד באבטיפוס
- מעבר בין בית, עסקאות, תחזית, תקציב והגדרות
- חיפוש וסינון עסקאות
- עריכת קטגוריה, הערה וסימון עסקה חריגה
- החלפת משתמש בין מתן ובת הזוג
- תצוגת תחזית, מועדי חיוב ותשלומים
- התקנה כ-PWA כאשר הקבצים מוגשים מאתר HTTPS

## הפעלה מקומית
יש לפתוח שרת קבצים מקומי בתיקייה. פתיחה ישירה של index.html תציג את המסכים, אבל Service Worker לא יפעל.

## חשוב
זהו אבטיפוס מסכים עובד עם נתוני דוגמה. השינויים נשמרים בזיכרון הדפדפן רק בזמן ההפעלה. החיבור ל-Google Sheets יתבצע בשלב הבא דרך Google Apps Script Web App, בלי לחשוף את מפתח ה-Service Account באפליקציה.
